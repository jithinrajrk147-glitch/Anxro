11

PWA Installation & Offline Use

Anxro is a Progressive Web App (PWA) installable directly from a browser — no app store required.

  • Installing the PWA adds an icon to your home screen and enables offline functionality.
  • Core features work offline once the PWA is installed and resources are cached by the service worker.
  • Features requiring live data (crypto prices, AI API calls) need an active internet connection.
  • PWA updates are delivered automatically in the background when connected to the internet.
  • Anxro does not request access to your camera, microphone, contacts, or SMS.
  • Uninstalling the PWA removes the home screen icon; cached data may persist until manually cleared.

Anxro PWA is optimized for mobile devices — best experienced on Android and iOS. Desktop installation is also supported.
